TrafficStat: what we saved, precinct by precinct

TrafficStat is NYPD's weekly report on traffic safety in each precinct: crashes, injuries and deaths by mode, DWI arrests, and parking and moving summonses. NYPD began posting a file for each precinct in August 2024 and replaces it every week.

Before this archive started, the only old copies were the ones the Internet Archive's Wayback Machine had saved. We downloaded all of them.
