NYPD's weekly precinct numbers, saved before they are replaced

Every week, NYPD posts traffic and crime statistics for each of the city's 78 precincts on nyc.gov, as Excel and PDF files. The next week's files go up at the same addresses and the old ones are gone. NYPD does not publish these weekly figures as datasets on NYC Open Data, so once a file is replaced, that week is no longer available from the City.

We save a copy of every file each week, turn the spreadsheets into tidy CSV files, and publish both here for anyone to use.

What we save #

Seven NYPD reports have their own pages below, each replaced every week. We read the list of files from NYPD's own pages on every run, so a new precinct or a renamed file is picked up without anyone editing a list.

How it works #

A scheduled job runs every Thursday and Saturday. NYPD replaces its files on Mondays and Tuesdays, so both runs land after a week's files are posted and before they are replaced. The job asks nyc.gov only for files that changed, one request at a time.

Each original file is kept exactly as NYPD published it, with its checksum, in the repository's GitHub Releases. The spreadsheets are then reshaped into CSV files with one number per row. If NYPD changes a file's layout, the job stops and says so rather than guess.

For the weeks before the archive started, we download the TrafficStat, CompStat, citywide and Department of Correction CompStat, and NYCHA Housing Bureau files that the Wayback Machine holds and check each against the Wayback Machine's own checksum. For CompStat we also brought in the PDFs Aaron Schumacher saved and the numbers Tim McDermott and Josh Greenman pulled from NYPD's reports; the CompStat page says which came from where.

Use the data #

  • Tidy CSV files, one file per series per week. The README explains every column.
  • NYPD's original files, zipped by week.
  • captures.csv, the ledger: every file saved, where it came from, and its checksum.
  • The data behind the charts: TrafficStat, CompStat, traffic fatalities, quality of life, citywide CompStat, Department of Correction CompStat, NYCHA Housing Bureau report.
Not an official record. NYPD calls these figures preliminary and subject to change. BetaNYC reshaped the spreadsheets into one number per row and left out NYPD's "change" columns, which can be worked out from the two years beside them. The original files in the releases are NYPD's, unchanged. For official figures, go to NYPD's statistics pages.
