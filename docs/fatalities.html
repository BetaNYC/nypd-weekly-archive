Traffic fatalities: which weeks survive, precinct by precinct

Every week NYPD posts one traffic fatality file for each patrol borough, plus one for the Port Authority Police. Each file lists traffic deaths in each precinct for the last 7 days, the last 28 days and the year to date, against the same periods a year earlier. The next week's files replace them.

This archive began saving them in November 2026. Each square below is one precinct for one week, taken from the precinct rows inside the patrol borough files.

Not an official record. NYPD calls these figures preliminary and subject to change. BetaNYC reshaped the spreadsheets into one number per row and left out NYPD's "change" columns, which can be worked out from the two years beside them. The original files in the releases are NYPD's, unchanged. For official figures, go to NYPD's statistics pages.
