About the NYPD Weekly Archive

NYPD posts its weekly precinct statistics on nyc.gov and replaces them the next week. We save a copy of every file, every week, and publish them here so the numbers stay public.

Built by BetaNYC #

BetaNYC is New York's civic organization dedicated to improving lives through public interest technology, open data, and civic design. We build tools, train the public, and advocate for a more transparent, accountable, and participatory city government. BetaNYC is a project of the Fund for the City of New York.

Others saved these files long before we did, and this archive builds on their work:

  • Aaron Schumacher saved NYPD's CompStat PDFs from 2014 to 2016 (ajschumacher/nypd).
  • Tim McDermott, a BetaNYC volunteer, turned the weekly CompStat reports into CSV files from 2015 to February 2026.
  • Josh Greenman's nypd-compstat-scraper has read NYPD's CompStat spreadsheets since March 2026. We use his numbers with his permission.
  • The Internet Archive's Wayback Machine holds copies of many of NYPD's files from earlier years.

How we use AI #

BetaNYC uses AI tools openly and with human accountability. The code that saves and reads NYPD's files, and the pages of this site, were written with help from AI coding assistants, under the direction and review of BetaNYC staff. Automated tests check the code on every change.

The numbers are not written by AI. A program copies them from NYPD's own spreadsheets, cell by cell, and stops if a file's layout changes rather than guess. NYPD's original files are kept unchanged in the releases, so you can check any number against the file it came from.

Read BetaNYC's AI policy. Questions about our approach: lab@beta.nyc.

Licensing #

The code is released under the MIT License. You may use, copy, and change it for any purpose, as long as the license notice stays with it.

The figures are NYPD's. They are public records from the New York City Police Department, and the license covers our code, not NYPD's data. The CompStat numbers from Tim McDermott's files and from Josh Greenman's scraper are credited to them on the CompStat page; please keep that credit, and the link to Josh's repository, if you reuse them.

If you use this archive, please credit BetaNYC and link to the repository.

Contributing #

Found a wrong number, a missing week, or an NYPD file we don't save? Open an issue on GitHub. Pull requests are welcome.

Every change to the published data, or to where the files are kept, is listed on What's changed, and so is every correction when we get something wrong.

If you saved any of NYPD's weekly files yourself, from any week before November 2026, we would like to hear from you. Each one can fill a gap in the charts.
